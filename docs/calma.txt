5. E o conteúdo?
Como o header e o sidebar são fixed, precisamos dar espaço para eles.

Adicione:

.main {
    margin-left: 240px;
    padding: 100px 30px 30px;

    width: calc(100% - 240px);
    min-height: 100vh;
}

6. O detalhe importante para o seu sistema
Depois nós vamos parar de escrever isso manualmente:

<a href="pacientes.html">Pacientes</a>
<a href="consultas.html">Consultas</a>
<a href="exames.html">Exames</a>

para cada perfil.

Porque você quer algo como:

ADMIN
├── Dashboard
├── Pacientes
├── Médicos
├── Funcionários
├── Convênios
├── Consultas
├── Exames
├── Medicamentos
└── Configurações

MÉDICO
├── Dashboard
├── Minhas consultas
├── Meus pacientes
├── Exames
└── Receitas

PACIENTE
├── Dashboard
├── Minhas consultas
├── Meus exames
└── Minhas receitas

Então o mesmo sidebar será montado de acordo com:

usuario.perfil

E aí começa a ficar bem legal, porque você terá uma estrutura:

                 LOGIN
                   ↓
              usuario
                   ↓
                perfil
                   ↓
        ┌──────────┼──────────┐
        ↓          ↓          ↓
      ADMIN      MÉDICO    PACIENTE
        ↓          ↓          ↓
      menu       menu       menu
        ↓          ↓          ↓
    dashboard  dashboard  dashboard

Eu começaria exatamente por esse layout. Depois colocamos os cards do dashboard e, em seguida, fazemos o menu ser carregado automaticamente conforme o perfil do seu banco.
